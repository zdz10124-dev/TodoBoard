# 待办面板（TodoBoard）

一个常驻桌面的深色半透明待办清单。**零第三方依赖**，只用 Python 标准库 + tkinter，
不装任何东西、不联网、不同步账号，数据就是本目录下的一个 `data.json`。

---

## 快速开始

需要 **Python 3**（Windows 官方的安装包自带 tkinter）。**零第三方依赖**，
不需要 `pip install` 任何东西，不联网。

1. 把 `TodoBoard.pyw` 放进任意目录
2. 双击它 —— `.pyw` 后缀不会弹黑色控制台窗口

首次运行会在**同目录**自动生成 `data.json`，里面是一份示例任务，随手改掉就行。

| 想要 | 怎么做 |
|---|---|
| 桌面快捷方式 | 右键 `TodoBoard.pyw` → 发送到 → 桌面快捷方式 |
| 快捷方式换图标 | 右键快捷方式 → 属性 → 更改图标 → 选同目录的 `icon.ico` |
| 开机自动启动 | 面板的「⚙ 设置」里勾上「开机自动启动」 |

**只允许开一个窗口。** 重复双击不会开出第二个，正在运行的那个会保持原样。

## 界面速览

每一栏都是**一扇独立的小窗**，可以各自拖到屏幕的任何地方，互不牵连：

```
┌─────────────────┐  ┌─────────────────┐
│ ┊ 我的待办 3 ⌦ ⋯│  │ ┊ 长期目标 2 ⌦ ⋯│    ┌────────────────┐
├─────────────────┤  ├─────────────────┤    │ ＋ ↺ ↻ ▲ ⌄ ⚙ ✕ │ ← 工具条
│ ○ 交周报   逾期×│  │ ○ 读《人月神话》×│    └────────────────┘
│   今晚前发给组里│  │   每天 20 页    │
│ ─────────────── │  │ ─────────────── │
│ ● 取快递   完成×│  │ ○ 英语口语     ×│
│ ─────────────── │  │ ─────────────── │
│ ⊕ 添加任务      │  │ ⊕ 添加任务      │
└─────────────────┘  └─────────────────┘
      ↑ 拖左右边缘可以改宽窄
```

排布学的是邮件列表 / iOS 列表：**一条任务就是一行、占满整个栏宽**，不加卡片、
不加边框。左边一个勾选圈，标题和内容左对齐，截止时间挂在标题那一行的最右边。
行与行之间只有一条发丝线，而且这条线从左内边距开始 —— 和文字左边缘对齐。

### 工具条

窗口里没有「一整块面板」了，那几个全局按钮另外放在一条小小的工具条上：

| 图标 | 作用 |
|---|---|
| ＋ **新建分栏** | 在最右边再开一栏（放不下就换到下一排） |
| ↺ **撤回** | 退回上一步。灰着＝没什么可撤的了 |
| ↻ **重做** | 把刚撤回的那步再做一遍 |
| ▲ **置顶** | 亮琥珀＝所有栏都浮在最上层；点一下变灰＝压到桌面层（只露在桌面上，会被别的窗口盖住） |
| ⌄ **收起** | 把所有栏压成只剩标题条，再点展开（不占地方，又不会找不回来） |
| ⚙ **设置** | 改透明度、毛玻璃、新分栏的默认宽度、提醒、开机自启 |
| ✕ **关闭** | 退出程序（所有改动已即时保存，直接关不会丢） |

> ⚠️ **默认是置顶的**，也就是一直浮在最前面。栏本身也是可以点的窗口，所以如果
> 你在它的位置上点鼠标，点到的是**栏**而不是下面的程序。
> 觉得碍事就点 ▲ 关掉置顶，或者点 ⌄ 收起。

### 它不在任务栏上

这程序**不会在屏幕下方的任务栏里占一个按钮**。它的图标在任务栏**最右边那个
折叠区**里（点一下 `∧` 展开的那一小块），和微信、QQ 那些图标待在一起 —— 桌面
下方因此干干净净，不会多出一个「待办面板」。

在那个图标上**单击或者右键**都会弹出菜单：

| 菜单项 | 作用 |
|---|---|
| 显示 / 隐藏待办面板 | 把所有栏从屏幕上整个收起来，或者再放回来 |
| 展开 / 收起全部栏 | 和工具条的 ⌄ 一样 |
| 设置… | 和工具条的 ⚙ 一样 |
| 退出 | 和工具条的 ✕ 一样 |

「隐藏」只是不显示，程序还活着：数据、提醒、计时全照常跑。想找回来就在托盘
菜单里点「显示待办面板」（菜单里这一项的名字会跟着当前状态变）。

程序退出时会把图标摘干净 —— 不会在折叠区里留下一个点不动的死图标。

## 基本操作

| 想干什么 | 怎么做 |
|---|---|
| 加任务 | 点分栏底部的「＋ 添加任务」，或**双击分栏空白处** |
| 改任务 | **单击任务行**打开编辑窗 |
| 打勾完成 | **点行左边的圆圈**，完成会加删除线并变暗（再点一下取消） |
| 删任务 | **点任务行最右边的「×」**（直接删，不弹确认，会浮出「撤销」）；也可以用编辑窗左下角的「删除」或任务行的右键菜单 |
| 清空一栏 | 点栏标题右边的**垃圾桶图标**，或「⋯ → 清空本栏任务」 |
| 调顺序 | **按住任务行拖**，会看到一条琥珀色插入线，松手落位 |
| 换分栏 | 直接拖到另一栏；也可以在编辑窗里改「所属分栏」 |
| 滚动 | 鼠标停在某一栏上滚滚轮 |
| **挪动整栏** | 拖它顶上的标题条，或拖栏里的空白处 |
| **改栏宽窄** | 拖栏的**左边缘或右边缘**；拖下边缘改高度 |
| 加/删分栏 | 工具条的「＋」新建；栏标题右边的「⋯」可以重命名、换颜色、删除 |
| 换栏的颜色 | 「⋯ → 更换颜色」——**整块玻璃**都会染上这个色（见下） |
| 找不着栏了 | 设置里点「重新排列分栏」，所有栏回到屏幕右上角排成一排 |

**换颜色换的是整块玻璃。** 不只是标题条上那根小竖条 —— 这栏的底色、标题条、
任务区会一起染上这个色相，一眼就能看出「这栏是暖的、那栏是冷的」。底色始终很
深（和面板黑混到只剩一成多的色相），所以文字照旧清楚，不会变成一块荧光板。
嫌浓或嫌淡，改代码里的 `GLASS_DYE`（见「给它换个样子」）。

- 栏拖到屏幕边缘、或者靠近别的栏时会**自动吸附对齐**。
- 位置、宽度、高度都会被记住，下次打开还是原样。
- 删除分栏时，里面的任务**不会消失**，会移到第一个分栏里。

## 撤回、重做与操作日志

工具条上那两个弧线箭头就是**撤回**和**重做**。整个界面里凡是"改动了数据"的
动作都会进撤回栈：新建 / 编辑 / 完成 / 取消完成 / 删除 / 复制 / 移动任务，
新建 / 改名 / 换色 / 清空 / 删除分栏。

几个要留意的：

- **没设快捷键。** 这是桌面角落的一块小面板，Ctrl+Z 有可能被别的程序占着，
  抢过来会打架 —— 要用就点那两下。
- **删任务和清空分栏不弹确认框**，动作照样进撤回栈，删完屏幕上方浮出一条
  「已删除「xxx」· 撤销」，五秒内点「撤销」就回来了。手快的话根本不会看见它。
- **撤回栈只在内存里**，关掉程序就清空。重启之后没有"上一步"可退 —— 那是
  昨天的事，退回去反而莫名其妙。
- 撤销栈最多记住 200 步，超出就把最老的挤掉。

### 日志文件

和撤回栈同时记的还有一份**给人看的**日志：`activity.log`，就在程序目录下。
纯文本、UTF-8、记事本直接打开，一行一件事：

```
2026-10-09 18:59:35  完成「交周报」
2026-10-09 19:02:11  新建任务「买酱油」→ 短期目标
2026-10-09 19:04:02  删除任务「取快递」→ 短期目标
2026-10-09 19:04:40  撤回:删除任务「取快递」→ 短期目标
2026-10-09 19:31:07  清空分栏「长期目标」(3 条)
```

它和 `data.json` 是两回事：`data.json` 是程序读的当前状态，`activity.log`
是**流水账**，只往里写、从不回改。所以"这条是什么时候没的"翻日志就知道。
超过 1MB 会自动把旧的挪成 `activity.log.1`（只留一代）。

## 截止时间怎么写

编辑窗里的「截止时间」框很宽容，下面这些都认：

| 输入 | 含义 |
|---|---|
| `2026-12-25 18:30` | 具体日期时间 |
| `12-25` | 今年 12 月 25 日 23:59 |
| `今天 18:00` / `明天 9:30` / `后天` | 相对日，不写时间默认 23:59 |
| `周日` / `星期三` / `礼拜五` | 下一个那天 23:59 |
| `18:00` | 今天 18:00；已经过了就顺延到明天 |

懒得打就用下面的快捷键：日期 `今天 / 明天 / 本周日 / 下周`，时间 `09:00 / 12:00 / 18:00 / 21:00`。
右边的「清除」按钮清空截止时间。

**颜色规则**：已逾期显示红色，1 小时内到期显示琥珀色，其余中性灰，已完成一律
暗灰。整个界面只有「置顶指示灯」和「逾期/临近」这两处会用彩色，别处都是黑白灰。

### 有截止时间的任务，勾选圈会走路

行左边那个圆圈同时也是**一个小表盘**：一圈弧从十二点开始顺时针长过去，长满
就到点。起点是这条任务**创建的时间** —— 也就是说，这个环量的是"我留了多久、
还剩多久"，比一个孤零零的时间数字直观。

弧的颜色跟着剩余时间走：还早就中性灰，剩不到 1 小时变琥珀，**逾期变红并且
长满一整圈**。

**快结束的时候它会轻轻震。** 剩余不足 **5%** 或者不足 **1 分钟**时，那个环会
左右轻轻抖一拍（1.5 像素、90 毫秒一个相位）—— 幅度小到像在呼吸，不像在闪。
整块面板上只有它一个东西会动，所以那一下就足够醒目了。

**逾期之后就不抖了。** 抖是「快到点了」这句话，说过了就该停；让一个已经逾期
的任务抖到天荒地老，那是噪音不是提醒。

没有截止时间的任务，那个圈就还是个普普通通的勾选圈，什么也不显示。

## 提醒

- 默认**不提醒**。新建任务时提醒是关的 —— 每条任务可以在编辑窗里单独设
  （不提醒 / 到点 / 10 分钟 / 30 分钟 / 1 小时 / 2 小时 / 1 天），
  也可以在设置里改「新任务默认提前多久提醒」，比如设成「提前 1 小时」。
- 不提醒的任务**不影响那个进度环** —— 环只看截止时间，和提不提醒是两回事。
- 到点时屏幕右下角浮出一张提醒卡片，同时有一声提示音（可在设置里关）。
- 卡片上有三个按钮：**知道了** / **稍后 10 分钟** / **打开任务**。
- 程序每 30 秒检查一次，所以就算栏被收起，提醒照样会弹。
- 提醒过一次就不会重复提醒，除非你点「稍后 10 分钟」。

## 设置里有什么

| 项 | 说明 |
|---|---|
| 面板不透明度 | 0.40（很透）～ 1.00（完全不透），拖动即时生效，所有栏一起变 |
| 毛玻璃背景 | 把背后的窗口**模糊**掉（而不是原样透上来）。见下面「关于毛玻璃」 |
| 新分栏的默认宽度 | **只影响以后新建的栏**。已经在的栏各有各的宽度，想改就拖它自己的左右边缘 |
| 新任务默认提前多久提醒 | 新建任务时的默认值，**出厂是「不提醒」** |
| 提醒时播放提示音 | 提醒时是否响一声 |
| 隐藏已完成的任务 | 打勾完成的任务直接从栏里藏起来 |
| 开机自动启动 | 开关 |
| 重新排列分栏 | 把拖散的栏全部收回屏幕右上角、排成一排（找不到窗口时的救命按钮） |

### 关于毛玻璃

老式的「半透明」是**把背景按比例混进来**：面板 88% 不透明，背后那 12% 就照
原样透上来。背后是一屏文字（终端、浏览器、聊天记录）的时候，那些字会和面板
自己的字叠在一起，看着像贴了张半透明纸 —— 又脏又廉价。

打开「毛玻璃背景」之后，Windows 会先把背后**模糊**掉再贴过来。于是：

- 背后有什么几乎看不出来，但整栏仍然"透"，能感到桌面在流动；
- 栏里的文字始终清晰，不会被背景干扰；
- 可以放心把不透明度调低（**推荐 0.72 ～ 0.80**），透得越多越好看。

如果系统不支持（老 Windows、远程桌面、个别显卡驱动），这个开关会自动失效并
退回原来的均匀半透明 —— 只是少个装饰效果，不影响任何功能。

## 数据与备份

- 数据文件：`data.json`，和 `TodoBoard.pyw` 放在同一个目录，**UTF-8 编码**，
  可以直接用记事本打开看。
- 操作流水：`activity.log`，同目录，同样是纯文本，追加写、不回改。
- 每一次改动都立刻写盘（先写临时文件再原子替换），断电不会写坏。
- 如果文件被改坏了，程序会自动把它备份成 `data.json.broken` 再回到默认状态，不会崩。
- **备份就是复制这两个文件。**

## 遇到问题

| 现象 | 处理 |
|---|---|
| 点了两次没反应 | 已经有一个在运行了；程序刻意不重复开窗 |
| 任务栏里找不到它 | 它本来就不在任务栏上，图标在任务栏**右边的折叠区**里（点 `∧` 展开） |
| 所有栏都不见了 | 多半是托盘菜单里点了「隐藏待办面板」→ 再从托盘菜单点「显示待办面板」 |
| 某一栏不见了 | 可能被拖到屏幕外了 → 设置里点「重新排列分栏」 |
| 想彻底退出 | 托盘菜单「退出」、工具条 ✕、任务行右键菜单「退出」、`Alt+F4` 都行 |
| 觉得太透/不透 | 设置里拖「不透明度」 |
| 挡住别的程序 | 点 ▲ 取消置顶，或点 ⌄ 收起 |
| 只想改其中一栏的宽度 | 拖那一栏的左右边缘；设置里那条滑杆是给"以后新建的栏"用的 |
| 不小心点了叉号 | 提示条上的「撤销」，或工具条的 ↺（重启过就找不回了，见 activity.log）|
| 想查某条任务什么时候没的 | 打开 `activity.log` 找那一行 |

## 给它换个样子

想微调配色/尺寸，直接改 `TodoBoard.pyw` 开头的常量：

- `C_*` 是全部颜色，`PALETTE` 是新建分栏时轮流取的强调色
- `GLASS_DYE` 是栏色混进玻璃底的比例：**小 = 更花哨，大 = 更含蓄**，
  `1.0` 就是回到纯黑的中性玻璃。默认 `0.86`（试过 `0.80`，暖色那几栏会发土）
- `HEADER_H / PAD / COL_GAP / COL_PAD / COL_HDR_H / COL_W_DEF / CARD_PAD /
  ROW_PAD_Y` 是各处尺寸（逻辑像素，会按屏幕 DPI 自动缩放）
- `COL_GAP_OUT`（两扇栏窗之间的空档）、`EDGE_W`（左右边缘抓取宽度）、
  `COL_W_MIN` / `COL_H_MIN`（最窄最矮）、`TOOL_W` / `TOOL_PAD`（工具条；
  `TOOL_W` 是按图标个数算出来的，加减图标记得一起改）
- `RING_URGENT_PCT` / `RING_URGENT_SEC` 是「快结束了」的门槛（默认 5% / 1 分钟），
  `SHAKE_PX` / `SHAKE_MS` 是抖的幅度和节奏（默认 1.5 像素、90 毫秒），
  `RING_MIN_DEG` 是弧再短也得画出来的那一点（不然刚开始几乎看不见环）

改完保存，重启程序生效。

关闭毛玻璃（改了代码之后想排查问题），在设置里取消勾选「毛玻璃背景」即可，
或者启动前设环境变量 `TODOBOARD_NO_ACRYLIC=1`。

改动之前先看一眼文件开头那段设计原则，改出来的东西才不至于跑偏：

1. **只有一层表面。** 栏底和任务行底是同一个颜色。靠留白和 1px 发丝线分区，
   不再叠第二个方块。旧版面板/分栏/卡片/胶囊叠了四层近黑色，每层都得描边区分，
   于是到处是框 —— 那是最主要的"廉价感"来源。
2. **所有颜色都是中性近黑/近白，不偏蓝。** 偏蓝的近黑是"程序员的深色主题"
   的典型特征。
3. **只有一个强调色**（琥珀 `#E9A23B`），并且只在「置顶指示」和「逾期/临近」
   两处出现，别处一律中性灰。
4. **层次靠字重/字号/明度，不靠加框。** 正文分四级明度，从亮到暗逐级退后。
5. **栏色只染"玻璃"，不染"内容"。** 每栏底子带着自己那一点色相（`GLASS_DYE`），
   但文字、发丝线、按钮永远是中性的黑白灰 —— 染色是背景的事。这样几栏摆在一起
   是"几块不同的玻璃"，而不是"几张彩色卡片"。第 2 条说的"中性"针对的是**前景**，
   底色是唯一允许带色相的地方。

## 附一：为什么每栏是一扇独立的窗

早期版本是「一整块面板里横排几个分栏」。那样每栏只能跟着面板走，想把这个栏
放到屏幕左边、那个栏放到右边就做不到 —— 而桌面上的待办本来就该能随便摆。

拆开之后每一栏自己就是 `tk.Toplevel`，各自记自己的位置和尺寸，想拖哪栏拖哪栏。
代价是窗口变多（多睡醒一次要各自的圆角和毛玻璃），所以背景是**在窗口建好之后**
才逐个挂上去的，挂不上就退化成普通半透明，不影响用。

## 附二：开发者用的调试开关

| 环境变量 | 作用 |
|---|---|
| `TODOBOARD_DEBUG=1` | 把 DPI / 窗口尺寸 / 位置打到 stdout |
| `TODOBOARD_DEV=<目录>` | 改用 `<目录>\data.json` 和 `<目录>\activity.log`，并跳过单实例锁，可以在不打断正在运行的主程序的前提下另开一个调界面（也保证调界面时不会把真实日志搅乱）|
| `TODOBOARD_NO_ACRYLIC=1` | 强制关掉毛玻璃（排除"是不是模糊导致的"）|
